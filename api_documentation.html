Expanded E-commerce API Documentation (Toy Demo)

Date: May 1, 2025

Overview

This API provides access to an e-commerce startup's database with data on customers, products, and orders. It uses sqldf in R to query three tables: customers, products, and orders.

Database Schema

  • customer_id (integer): Unique ID for each customer (1 to 300).
  • name (string): Customer name (e.g., "Customer 1").
  • email (string): Customer email (e.g., "customer1@startup.com").
  • city (string): Customer city (Delhi, Mumbai, Bangalore, Hyderabad, Ahmedabad, Chennai, Kolkata, Surat, Pune, Jaipur).
  • product_id (integer): Unique ID for each product (1 to 100).
  • product_name (string): Product name (e.g., "Product 1").
  • category (string): Product category (Electronics, Fashion, Books, Home, Toys).
  • price (numeric): Product price (between 100 and 1500).
  • order_id (integer): Unique ID for each order (1 to 1500).
  • customer_id (integer): ID of the customer who placed the order.
  • product_id (integer): ID of the product ordered.
  • quantity (integer): Quantity ordered (1 to 10).
  • order_date (date): Date of the order (between 2025-01-01 and 2025-04-30).

Available Endpoints (Simulated in R)

  • Function Name: get_best_selling_product_sales_in_city(city)
  • Description: Retrieves the total sales of the best-selling product (by total amount) in a specified city.
  • Parameters:
    • city (string): The city to filter by (e.g., "Chennai").
  • Returns: JSON object with columns: product_name, total_sales.
  • Example Query: Returns the best-selling product in Chennai.
  • Function Name: get_bottom_cities_by_sales(num_cities)
  • Description: Retrieves the bottom N cities by total sales.
  • Parameters:
    • num_cities (integer): Number of cities to return (e.g., 3).
  • Returns: JSON array with columns: city, total_sales.
  • Example Query: Returns the bottom 3 cities by sales.
  • Function Name: get_top_products_by_quantity_in_city(city, num_products)
  • Description: Retrieves the top N products by total quantity sold in a specified city.
  • Parameters:
    • city (string): The city to filter by (e.g., "Bangalore").
    • num_products (integer): Number of products to return (e.g., 5).
  • Returns: JSON array with columns: product_name, total_quantity.
  • Example Query: Returns the top 5 products by quantity in Bangalore.
  • Function Name: get_orders_count_by_city_and_month(city, month, year)
  • Description: Counts the number of orders in a specified city for a given month and year.
  • Parameters:
    • city (string): The city to filter by (e.g., "Hyderabad").
    • month (string): The month (e.g., "03" for March).
    • year (integer): The year (e.g., 2025).
  • Returns: JSON object with column: order_count.
  • Example Query: Returns the number of orders in Hyderabad in March 2025.
  • Function Name: get_avg_order_value_by_category_and_city(category, city)
  • Description: Calculates the average order value (price * quantity) for a specified category in a specified city.
  • Parameters:
    • category (string): The product category (e.g., "Electronics").
    • city (string): The city to filter by (e.g., "Mumbai").
  • Returns: JSON object with column: avg_order_value.
  • Example Query: Returns the average order value for Electronics in Mumbai.

Notes

  • The API uses sqldf to run SQL queries on R DataFrames (customers, products, orders).
  • Total amount for an order is calculated as price * quantity.
  • Dates are in 'YYYY-MM-DD' format; use strftime() for date filtering (e.g., strftime('%m', order_date) for month).
  • The API is simulated in R for demo purposes.
